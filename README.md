# Overworld

A tiny, vibe-coded isometric weather utility. No build step, no API keys, no clutter — just current conditions, next 24 hours, 7-day forecast, and an expandable pixel-art radar.

## Notes
- Built purely as a personal static HTML/CSS/JS utility (`index.html`, `styles.css`, `js/`).
- Powered by free, keyless endpoints: [Open-Meteo](https://open-meteo.com/), [NWS](https://www.weather.gov/), [NOAA Mesonet](https://mesonet.agron.iastate.edu/), [RainViewer](https://www.rainviewer.com/), [OpenFreeMap](https://openfreemap.org/), and [BigDataCloud](https://www.bigdatacloud.com/).
- Saved locations can be reordered, deleted, and swiped between horizontally.

## Local Preview
```sh
python3 -m http.server 8123
```
